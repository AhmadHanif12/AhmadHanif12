# Ahmad Hanif

**Software engineer · Speech AI, LLM systems & backend platforms**

I build production software around speech, language models, and business workflows — from the model pipeline to the API, the dashboard, and the server.

My recent work spans call quality evaluation, speech recognition, speaker diarization, and multi-tenant HR platforms. I work across implementation, deployment, and the debugging that follows.

## What I work on

- **Speech systems:** ASR pipelines, speaker diarization, speaker presence detection, and transcription quality across real telephone audio.
- **LLM applications:** structured evaluation, information extraction, prompt design, output validation, and integrations across model providers.
- **Business platforms:** multi-tenant HR workflows, payroll, attendance, scoped access control, and telephony integrations.
- **Production engineering:** async APIs, background workers, self-hosted inference, GPU services, monitoring, and deployment.
